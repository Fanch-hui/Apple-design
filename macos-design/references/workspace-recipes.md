# 工作区布局配方

依据《macOS 原生应用设计规范 · 视觉精修版》。示例尺寸均为内容区域内的项目起点，实际断点由各栏最低可用宽度、分隔线和内边距计算。保留系统窗口几何、可调整分栏及面板恢复入口。[资料出处](sources.md)

## 宽度推导

| 区域 | 初始 / 可调起点 | 空间不足时 |
| --- | --- | --- |
| 侧边栏 | 240pt / 200–300pt | 收起并保留显示入口 |
| 条目列 | 320pt / 280–400pt | 次要信息移至副行 |
| 检查器 | 288pt / 260–360pt | 标签置上，再收起 |
| 详情 | 弹性，示例最小 420pt | 切换为列表和详情的层级导航 |
| 阅读列 | 随窗口调整，常见 500–720pt | 先收窄行长，再纵向滚动 |

三栏资料库示例：`1200 = 240 + 1 + 320 + 1 + 638`。详情左右各 24pt 后正文宽 590pt。按 `200 + 1 + 280 + 1 + 420 = 902pt` 估算三栏下限，低于此值可先收起侧边栏；两栏下限 `280 + 1 + 420 = 701pt`，再收窄可分时呈现列表和详情。具体项目按文字、操作与用户调整重新计算，并保留选中、筛选和滚动。

项目工作台示例：`1200 = 240 + 1 + 670 + 1 + 288`。若中央区最少 560pt，三栏下限为 `200 + 1 + 560 + 1 + 260 = 1022pt`。低于下限可先收起检查器，并提供恢复入口。

## 按任务选结构

| 任务 | 构成与视觉起点 | 收窄与持续状态 |
| --- | --- | --- |
| 笔记、邮件、资料库 | 侧栏 240、条目列 320、详情弹性；条目双行 52pt；详情正文 16/24pt，水平边距 24pt | 先收侧栏，再将列表与详情分时呈现；保留过滤和选中 |
| 项目工作台 | 侧栏 + 弹性表格 + 检查器 288；中央边距 20pt，标准行 32pt | 先收检查器；选中项、列宽、焦点保持 |
| 跨记录比较 | 侧栏 + 宽表格；名称列弹性、数字列尾端对齐，筛选与排序靠近表头 | 保留比较所需列，允许横向滚动，列设置可找回隐藏列 |
| 创作编辑器 | 资源栏 + 画布 + 检查器；资源行 32pt、层级缩进 16pt；画布为视觉主体 | 先收检查器再收资源栏；维持画布位置与缩放中心 |
| 设置 | 分类栏 + 表单，示例 `760 = 200 + 1 + 559`；内容左右 24pt，分区间距 24pt | 长标签改上下排列；恢复上次分类，保持系统设置入口 |
| 单任务工具 | 示例宽 640pt，左右 24pt；标题 22/26pt，输入及结果按任务组织 | 控件先纵向排列，结果保留复制、保存或打开入口 |
| 菜单栏扩展 | Popover 示例宽 320pt，左右 16pt；状态与高频动作优先 | 长内容可滚动，完整历史或复杂编辑进入独立窗口 |

侧边栏自定义行示例：240pt 栏宽、左右 12pt，选中面宽 216pt；内容从面板内再缩进 8pt，20pt 图标槽后留 8pt，文字起点为 48pt。组标题可从 20pt 开始，子层级缩进 16pt。系统侧边栏随用户显示偏好变化，以上几何用于自定义内容。
