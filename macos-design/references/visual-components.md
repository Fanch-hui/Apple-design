# 自定义组件视觉规格

依据《macOS 原生应用设计规范 · 视觉精修版》。以下是自绘业务内容的起点，适合的系统控件优先使用自身尺寸、焦点与状态。每个组件同时考虑内容、几何、文字、前景/背景、默认/悬停/按下/禁用/加载/错误状态和键盘路径。[资料出处](sources.md)

## 按钮与对象行

常规自定义按钮 32pt 高，主按钮 36pt；标签 13pt Medium 或 Semibold，水平内边距 12pt，图文间距 6pt，图形 16pt，圆角 8pt。图标按钮可用 28pt 命中槽。标签和加载内容共用稳定宽度，长标签先增加宽度或调整相邻布局。

| 对象行角色 | 单行起点 | 双行起点 |
| --- | --- | --- |
| 行高 | 32pt | 52pt |
| 水平 / 垂直内边距 | 12 / 8pt | 12 / 10pt |
| 图像 | 16pt 图标在 20pt 槽 | 32pt 缩略图或 24pt 符号 |
| 图文间距 | 8pt | 12pt |
| 主 / 次文字 | 13/16pt、11/14pt | 13/16pt、11/14pt，两行间 2pt |
| 尾部操作 | 28pt 槽 | 28pt 槽 |

文本增长时行高随内容增长。自定义行预留操作槽，Hover 或加载状态不挤动名称；选择、动作与双击打开各有清楚作用范围。失焦时保留可识别的选择，多选将批量操作放在稳定区域。

## 表格与搜索

自定义数据表表头和标准行从 32pt 开始，紧凑行 28pt，舒适行 40pt；表头 11–12pt、正文 13pt。名称列弹性伸缩，数值及单位统一格式并尾端对齐。以最长实际示例推导列宽，名称列可从 140–180pt、日期列 132–160pt、状态列 80–104pt 起算。用户可调整列宽、排序与列显示，横向空间不足时保留关键比较列并允许横向滚动。[A14][V16]

搜索范围按入口表达：全局搜索在工具栏，集合内搜索在列表顶部。自定义字段可从高 32pt、宽 220–280pt、图标 14pt、清除操作 28pt 开始；筛选控件可从高 28pt、文字 12/15pt 起算。查询时结果区展示进度，空结果提供清除条件；返回时保留对象和滚动位置。

## 字段与检查器

自定义输入框可从 32pt 高、左右 10pt 内边距、13pt 文字开始。持续显示字段标签；格式提示与错误靠近字段，失败时保留输入。短标签可用两列，长标签或窄面板改成上下排列；说明可从 11–12pt、与输入相距 4–6pt 开始。

288pt 检查器示例采用左右各 16pt，内部 256pt；短字段为标签 88 + 间距 12 + 输入 156pt。两并列输入为 `(256 - 8) / 2 = 124pt`；宽高联动可用 `106 + 8 + 28 + 8 + 106 = 256pt`。单位位置稳定，多选的混合值、空值和零值分别表达。输入、预览和焦点随用户操作保持对应。

布尔属性可用 Checkbox，统领一组功能的开关可用 Switch；枚举显示当前值，连续参数可提供 Slider 和精确数值输入。系统选择器、日期控件与文件面板保留平台语义。

## 其他常见组件

- **命令面板**：自定义宽度可从 560pt 起，可收至 440pt；搜索区 40pt、结果行 36pt，展示名称、作用对象和快捷键。方向键选择，Return 执行，Esc 关闭并恢复焦点。快捷键先检查现有冲突，完整命令仍可从菜单发现。
- **附件与导入队列**：附件行可从 56pt、32pt 预览槽、13pt 名称和 11pt 附加信息起算。展示等待、真实进度、完成或错误；提供适当的取消、重试、移除及文件选择入口，拖放有可用目标和预览。
- **状态与进度**：非交互状态标签可从 20–24pt 高、水平 6–8pt 内边距起算；可点击筛选有独立命中区。用文字表达状态，颜色和符号补充。长任务展示真实进度或明确阶段，失败给出恢复操作。
- **空状态**：自定义符号 32–48pt、标题 17/22pt、说明 13/18–20pt，可从图形到标题 12pt、标题到说明 8pt、说明到动作 16pt 开始。保留当前导航与筛选，提供与状态相关的下一步。
- **图表与指标**：指标共享数字基线和单位，区分变化方向与业务好坏。趋势用折线、类别比较用条形，精确比较提供表格。图例、系列颜色和单位保持稳定；缺失值和真实零值区分，图形信息提供文字或其他可访问方式。[V17]

## 状态与动效

选择、焦点、Hover 和窗口活跃状态可以同时存在：选中指当前对象，焦点指键盘作用位置，Hover 指指针位置。状态切换保留按钮、排序图标和行内操作的布局槽；错误文字与焦点环分别表达问题和输入位置。键盘与对象菜单可发现 Hover 出现的必要操作。[V13]

系统动效优先。自定义 Hover 80–120ms、按下 100–160ms、局部展开 160–220ms、检查器展开 180–240ms、列表重排 180–260ms 可作为起点。过渡应可打断，Reduce Motion 下使用直接变化或短淡变；拖动跟随指针，系统滚动保留原行为。

目标设备支持直接触摸时，结合目标系统能力考虑临时放大密集控件或扩大命中区，并让触摸揭示的操作与键盘、指针入口保持一致。实际系统 API 和行为随版本核对。[V18]
