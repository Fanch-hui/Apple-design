# 视觉基础与精修

依据《macOS 原生应用设计规范 · 视觉精修版》，资料检索日期为 2026-11-24。下列数值是自定义区域的项目起点，按内容、系统偏好和可用空间调整。系统窗口、菜单、侧边栏与标准控件使用运行系统的布局和外观；版本相关能力按目标 SDK 核对。[资料出处](sources.md)

## 密度与文字

| 自定义区域 | 字体起点 | 几何起点 | 适用任务 |
| --- | --- | --- | --- |
| 标准工作区 | 正文 13/16pt，标题 17/22pt，辅助 11/14pt | 行高 32pt，水平边距 20pt | 项目、表格、属性 |
| 密集工具 | 正文 13/16pt，分区标题 13–15pt | 行高 28pt，组内间距 4–8pt | 文件树、参数、监控 |
| 阅读编辑 | 正文 16/24pt，标题 22/26pt | 水平边距 24pt，阅读列 500–720pt | 文章、笔记、长报告 |

同一区域的同类行、字段、图标和按钮使用一致密度。段间距可从 12pt、章节间距从 24pt 开始；字号放大后允许换行和高度增长。文件名、URL、账户等可复制内容保留原文。数字、单位和相邻文字以基线对齐，计时和需要逐位比较的数字使用等宽数字。正文、标题与辅助信息形成稳定层次，重要说明保持可读。[V01][V02]

图文组合先定义文字前缘、文字基线、图标槽中心和容器边界四条关系。两行文字旁的图标可以对齐首行或居中于文字块，同一类对象保持一致。先建立几何对齐，再对不对称图形做小幅光学修正，修正放在组件内部，交互范围和文字轴保持稳定。

## 图标与品牌

- 系统动作优先用 SF Symbols，关联文字时匹配 text style、weight 和 scale，保留符号自然宽高与基线。[V03][V04]
- 自定义列表可从 20pt 图标槽、16pt 图形和 8pt 图文间距开始；独立工具图形 18–20pt，交互槽从 28×28pt 开始。系统工具栏和侧边栏采用系统尺寸。
- 固定画布的自制业务图标可从 24×24 画布、约 20×20 主图形区域、1.75 单位线宽开始。统一端点、连接和留白；小尺寸简化细节，以视觉重量微调圆形、长形及非对称图形。[V05][V06]
- 一级业务入口、陌生和风险动作使用明确文字；常见工具图标提供可访问名称和简短 Tooltip。关键操作规则直接显示在相关控件附近。
- App 图标使用原创品牌图形，依据当前官方模板制作图层、系统蒙版及外观。浅色、深色和着色版本共享可辨识的主体、负空间和比例。界面操作使用 SF Symbols。[V03][V07]

## 圆角、边界与像素

自定义小标签、缩略图、输入/按钮、面板和大型浮层可分别从 4、6、8、12、16pt 圆角开始。系统窗口和控件保留其形状。等距嵌套且角心一致的圆形角，可按 `内圆角 = max(0, 外圆角 - 外轮廓到内轮廓距离)` 起算，描边占据的厚度计入距离；非等距或连续曲率按实际轮廓调整。独立按钮保留自身角色圆角。[V08]

区分装饰分隔、控件边界和键盘焦点环。阴影表达悬浮或拖动，普通内容以背景、间距和轻分隔组织。自绘水平或垂直细线可根据实际 backing scale 对齐像素边界；1px 和 1pt 分别计算，曲线和文字保留抗锯齿。系统分隔线由平台处理。[V09][V10]

## 色彩与材质

先定义 Canvas、Surface、Inset、Primary/Secondary、Accent、Selection、Outline 与状态色，再成对定义浅深外观的前景和背景。导航与系统控件优先采用系统语义色、用户强调色和系统选中态。以下仅为冷中性灰与蓝色的自定义示例，可随品牌调整。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| canvas / surface / inset | `#F6F7F9` / `#FFFFFF` / `#EFF2F6` | `#121418` / `#1B1E24` / `#252A33` |
| text.primary / secondary | `#17212E` / `#566477` | `#F3F5F8` / `#B2BDCC` |
| accent / onAccent | `#285AD9` / `#FFFFFF` | `#90B5FF` / `#101B30` |
| selection.surface / text | `#EAF0FF` / `#285AD9` | `#223351` / `#90B5FF` |
| outline.control | `#728096` | `#7B889D` |
| success foreground / surface | `#146C3B` / `#EBF8F0` | `#8CE5AD` / `#193426` |
| warning foreground / surface | `#855500` / `#FFF5D6` | `#F7D386` / `#3C3118` |
| danger foreground / surface | `#B42318` / `#FFF0EF` | `#FFB4AB` / `#402525` |

文字及其实际背景一起检查对比。自定义正常文字可采用 W3C 的 4.5:1、传达必要信息的组件边界及图形采用 3:1 作为设计参考；颜色还应配合状态文字、形状或标记。透明层先与其实际背景合成再检查。系统语义色随平台外观与用户设置变化。[V11][V12]

Hover、Pressed、Selection、Focus 和窗口活跃状态分别表达。选中底色配套可读前景；键盘焦点环可叠加在选择或错误状态外，非活跃窗口仍保留对象选择。加载与状态切换尽量留在原槽位。Reduce Transparency 时自定义透明面板改用稳定不透明表面，Increase Contrast 时增强有意义的边界和选中标记。[V13][V14]

正文、表格和编辑器使用稳定内容面；结构面板依据语义选标准 Material；系统工具栏和悬浮控件遵循目标系统的玻璃角色。背景图片上的文字使用稳定衬底，图像模糊仅用于媒体，滚动边缘优先系统效果。自定义轻浮层、Popover 和拖动预览的阴影可分别从 `y=2 / blur=8 / 8–10%`、`y=8 / blur=24 / 12–16%`、`y=12 / blur=32 / 16–20%` 开始，按背景和渲染模型调整；系统浮层保留系统阴影。[V15]
