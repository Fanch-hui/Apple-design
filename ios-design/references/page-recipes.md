# 常见页面配方

综合 2026-11-24 视觉精修版第 02、09 章。按真实目标选择配方。下列数值为自定义内容的【推荐】起点，系统导航、列表和表单采用系统间距。

| 页面 | 阅读顺序和动作位置 | 宽度或高度变化 |
| --- | --- | --- |
| 项目 / 记录列表 | 用系统大标题表达当前区域，工具栏可放新建。需要时依次安排搜索、筛选、分组标题和连续列表。同类标题、描述与分隔线共享文字前缘 | 搜索低频时可收进工具栏。尾值拥挤时移到下一行，保持独立操作区。长名称和放大字体可增高行 |
| 对象详情 | 短导航标题，正文展示完整对象名或主图，再放状态、来源及关键内容。详情标题可用 22/28pt Semibold，分区间留 32pt | 短属性可双列，长值改成标签在上、值在下。相关操作并排时同高，文本拥挤转纵排 |
| 创建 / 编辑 | 顶栏提供任务身份、取消和保存。内容从第一个字段开始，持续标签与字段间约 8pt，字段组间约 24pt | 两个短且相关的字段可并排，其余单列。键盘出现时保留聚焦字段、错误说明和可达的完成动作 |
| 数据概览 | 一个主要指标建立焦点，之后为趋势、次要指标和明细。主数值可用 34pt，标签、单位和变化量用稳定角色 | 短指标在标签与数字均放得下时并排。不同维度的指标不能靠统一小字硬挤，转纵排或放入明细 |
| 阅读 / 媒体 | 封面可延展，正文用约 20pt 横向边距。标题 28/34pt，元信息 13/18pt，正文 17/26pt。段间 16pt，章节之前 32pt | 宽窗口限制正文行长。长标题可换行，封面保持裁切焦点，媒体控制保留独立触控区域 |
| 设置 / 账户 | 用系统分组列表。账户放首组，其余按外观、通知、同步或隐私分组。布尔值用系统开关，进入下级用披露附件，组 Footer 解释共同行为 | 长标签和长值支持换行或纵排。解释紧跟所属设置，保持可点击目标和阅读顺序 |

## 用可用空间计算

- 可用安全区宽 W，双侧边距 M，内容宽 C = W − 2M。列表文字宽 = C − 前导槽 − 图文距 − 尾随槽 − 附件距。网格项宽 = (C − (列数 − 1) × 列间距) ÷ 列数，以最小可读项宽决定列数。
- 390pt 示例，两侧各 16pt 得到 358pt 内容宽。28pt 图标槽、12pt 图文距、24pt 导航附件和 12pt 附件距之后，文字宽 282pt。若附件是独立的 44pt 更多按钮，文字宽 262pt。这个计算让点击边界和文字换行都可预测。
- 同一宽度下，两列间隔 12pt，每列 173pt。若卡片最低要 180pt，选单列；如果短指标在 173pt 内放得下，则可以双列。横屏、高比例字体或 iPad 分栏也按实际窗口推导。
- 检查首屏能立即看到主要内容，末项能完全滚到固定栏上方。适配宽窄布局时保留选中对象、查询、筛选与浏览位置。
