# 自定义组件视觉规格

以下尺寸来自 2026-11-24 视觉精修版第 07 章，是默认字号下的【推荐】起点。系统控件和导航的选择见[导航与组件](navigation-components.md)。先按组件的语义选系统实现，再给产品独有的内容补尺寸、文字、颜色、形状、状态和增长方式。

## 对象、查找与选择

| 组件 | 起点 | 交互、状态与增长 |
| --- | --- | --- |
| 对象行 | 单行 56pt、双行 72pt，紧凑记录 52/64pt。标题 17/22pt，说明 15/20pt，时间 13/18pt。图标槽 28pt，图文间 12pt | 短尾值与标题对齐，长尾值移到副行。进入箭头 24pt 槽，属于整行。独立更多按钮给 44pt 操作槽。大字号时行随内容增长 |
| 内容内搜索 | 48pt 视觉高，左右 12pt，20pt 放大镜，图文间 8pt，输入 17pt。清除按钮留 44pt 命中区 | 占位文案表达范围。清空输入与结束搜索分别命名。搜索、加载、无结果和重试期间保留关键词与筛选，结果在原位更新 |
| 筛选 Chip | 视觉高 32pt，长标签可用 36pt。文字 15pt Medium，左右 12pt，图文间 6pt | 可见胶囊放进 44pt 操作槽，命中区域彼此独立。已选态结合底色和标记。换行或横滚，复杂条件放入筛选 Sheet，保留可见的清除入口 |
| 分段选择 | 同一范围内 2–4 个短选项。自定义容器 36pt 视觉高起，外部操作区 44pt | 短标签等宽，内部选中面按同心关系处理。标题过长或选项过多时，用菜单或选择列表，当前值常显 |

## 输入、提交与反馈

| 组件 | 起点 | 交互、状态与增长 |
| --- | --- | --- |
| 主按钮 | 52pt 起，左右 20pt，17pt Semibold，图文间 8pt，圆角 16pt | 同组并排按钮同高，拥挤时改纵排。按最宽状态保留尺寸，执行中写明任务并防重复提交。只有明确语义的图标按钮可省略可见文案，仍留 44pt 操作区和可访问名称 |
| 输入字段 | 52pt 起，左右 16pt，17/22pt 输入，圆角 12pt。持续标签 15/20pt，与框间隔 8pt | 预留必要控件的独立操作槽。聚焦和错误通过清楚边界表达，错误文字贴近字段。多行增长，提交出错时聚焦首错并保留已有输入 |
| 底部输入条 | 最小视觉高度 52pt，17pt 输入，左右 12–16pt，附件和发送各 44pt | 输入增长到约 4–6 行后内部滚动。键盘打开时正文末项和任务动作仍可见，发送状态留在原位 |
| 进度 | 自定义进度条高 4–6pt，读数距进度条约 8pt | 已知总量显示真实完成量，未知总量写清正在做什么。按状态提供取消、暂停或重试。失败保留可恢复内容 |
| 空态 / 无结果 / 失败 | 主题图形 40–48pt、22pt Semibold 标题、15/20pt 解释。图到标题 16pt、标题到解释 8pt、解释到动作 24pt | 首次使用说明可创建什么；无结果给改词或清除条件入口；局部错误就地重试。权限状态说明具体功能受何影响，提供相应入口 |

## 媒体、卡片与指标

- **卡片**适合有独立身份、封面或可比较属性的对象。默认内边距 16pt，标题 17pt Semibold，摘要 15pt，元数据 13pt，标题至摘要 8pt。横向预览可用 64/72pt 缩略图，纵向封面可从 16:9 或 4:3 起步。多动作卡片明确区分进入详情与收藏等独立按钮，选中时保持卡片尺寸。
- **指标**由名称、数值、单位、时间范围和变化量组成。关键数字可用 28/34pt，单位 15–17pt 并共享基线，变化量 13pt 并带文字或方向标记。连续读数用等宽数字，跨项比较统一精度。标签或单位拥挤就转纵排。
- **图表**按任务选折线、条形或表格，标清时间、单位和范围。自绘折线可从 2pt 线宽和 4–6pt 选中点起步。系列用线型、标签或标记补足颜色差异。区分缺失和实际零值，筛选后保持类别颜色与读数格式。
- **占位**保留最终图像比例、裁切焦点与布局范围，内容加载后原位替换。局部刷新保留仍可用的内容和阅读位置。

跨组件的态色、焦点、对比和动效见[材质与动效](materials-motion.md)。凑不出足够的可读或触控空间时，先换行、移走次要信息或降低列数。
