## 核心设计决策

### 页面和导航

- 一个页面建立清楚的主任务与阅读起点，通过对齐、间距、字号和字重组织层级。相关信息自然分组，仅在需要独立预览、选择、拖动或明确边界时考虑卡片。
- Tab 表达一级区域；Navigation Stack 表达详情层级；Sheet 表达临时任务；Toolbar 和对象菜单承载动作。Tab 数量按业务确定，常见建议为 3–5 项。
- 一级列表可用 Large Title，详情通常用 Inline Title；正文已有清楚标题时省去重复身份信息。
- 返回和切换时保留相应滚动位置、搜索、筛选与浏览上下文。深链详情有清楚返回或关闭路径。
- 高频操作可见且靠近对象；低频操作放 Menu。搜索入口由范围、频率和现有底栏空间决定。

### 系统组件和内容状态

- 优先使用 `TabView`、`NavigationStack`、`List`、`Form`、`Section`、`Button`、`Picker`、`Toggle`、`DatePicker` 和系统 Sheet，以及对应 UIKit 组件。
- 常规记录使用列表；设置使用分组列表或表单；媒体集合可用网格。系统 inset、行高、控件形状和交互由系统布局管理。
- 业务表单保留可见字段标签，错误贴近字段并说明修复方式；适配键盘、焦点、自动填充与文本增长。操作失败时保留已输入内容。
- 为任务涉及的加载、空内容、无结果、失败和权限状态提供下一步。提交中的按钮保持稳定并避免重复执行。
- Menu 用于即时命令，Sheet 用于短任务，全屏用于复杂流程；Alert 留给需要立即处理的情况。危险操作按后果提供撤销或确认。

### 布局、排版和图标

- 使用 pt 和实际 Safe Area；系统栏与安全区由运行环境决定。以可用宽度、size class 和内容变化适配窄屏、横屏及宽屏。
- 使用系统语义字体和 Dynamic Type；标题、列表、按钮和容器随文字增长。正文优先 Body，信息层级控制在少量稳定样式。
- 文本、图标、附属值建立稳定列线；leading/trailing 跟随语言方向；金额和计时等需要比较的数字使用对齐及等宽数字。
- 优先 SF Symbols，统一视觉字重与尺寸。返回、关闭、搜索、分享、更多等熟悉且对象明确的低风险动作可以只用图标，并提供无障碍名称。
- 一级 Tab 保留短标签；陌生业务动作使用具体文字。说明只补充结果、前提或后果，放在控件附近或分区 Footer。

### 材质、运动和无障碍

- 使用系统语义背景、文本、分隔线和 Tint；状态同时通过文字、形状或图标表达。检查浅色、深色和高对比设置下的可读性。
- 在目标系统与 SDK 支持时，Liquid Glass 用于导航与浮动控件，内容表面使用标准背景或 Material。浮动栏覆盖滚动内容时优先系统 Scroll Edge Effect，默认 `automatic`；较早版本保留其系统导航和材质。
- Gaussian Blur 与渐进模糊用于媒体视觉处理；根据文字区域、图片和可读性调整，保持导航材质与图片处理的职责清楚。
- 采用系统 push/pop、Sheet、按压和选择反馈；自定义动画表达因果、位置或状态。手势保留系统边缘返回，快捷手势配备可发现入口。
- 触觉对应有意义的选择、拖动或结果。尊重 Reduce Motion、Reduce Transparency；提供 VoiceOver 名称、值和状态，保持阅读及焦点顺序。

## 自定义布局的常用起点

以下是原规范的默认建议；系统组件优先采用自身布局，文字放大时尺寸随内容增长。完整表见平台适配第 9.5 节。

| 项目 | 起点 |
| --- | --- |
| 水平边距 | 16pt；阅读页可用 20pt |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32pt；组内 8–12，组间 24–32 |
| 字体 | Body 17pt；次级 15–16pt；元信息 13pt；Large Title 34pt（适用时） |
| 触控目标 | 默认 44×44pt；图标可见大小约 18–24pt |
| 主按钮 | 48–56pt 起始高度，支持内容增长 |
| 自定义卡片 | 内边距 12–16pt，圆角 12–16pt |
| 自定义动效 | 微反馈约 100–200ms，一般过渡约 200–350ms |

## 交付与检查

设计任务给出符合需求的页面结构、组件选择、状态行为与必要视觉参数；实现任务遵循现有项目架构并完成实际修改；审查任务指出具体位置、体验影响和可执行的修复建议。

围绕当前改动检查导航路径、主要操作、键盘遮挡、内容增长、底部最后一行的可见性，以及相应的动态字体、深色模式、VoiceOver 和减少动态效果适配。代码任务按改动运行必要的编译、类型或业务验证。UI 交互和最终体验交由用户人工验收，自动化点击或页面走查须由用户明确要求。

用户明确选择网页或其他技术栈时，保留其实现平台，依照平台适配章节转换布局、路由、输入与无障碍语义。
